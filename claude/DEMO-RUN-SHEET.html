Office → Batch Costing → 2101. The only fully costed batch, and it is complete.

  • 10 material lines — resin, three grit sizes, filler, two pigments, two chemicals
  • 3 grit silos split across 3 suppliers, every line priced
  • 15 rate-card entries behind it; both sign-offs recorded
Only 2101 is costed. Every other batch shows an empty sheet. That is deliberate — the sheet refuses to total when a line is unpriced, so one batch done properly beats eighteen half-priced ones. Don't open another batch here.

08What not to open

The CEO report will look sparse. 120 QC rows across 21 June – 14 September — under two a day, and the busiest single day has four. Real production is thousands. If the report takes a date range, use the whole span and it reads fine; a single-day view will look nearly empty whichever day you pick. Ask for a denser reseed if you need this screen — it is a few minutes' work.
Nothing that sends. Email, Telegram, WhatsApp. The database is isolated; outbound messaging is not.
Salesforce sync. Not wired to the demo database, and its credentials point at the real org. Leave it alone.

10Refill the data

npm run demo:seed

Wipes pacificdemo and rebuilds it in about a minute — 3,852 rows. Safe any time: it refuses to start unless Postgres itself confirms the database is pacificdemo, and it can reach nothing else.
